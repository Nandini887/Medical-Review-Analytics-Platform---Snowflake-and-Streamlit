# Independent Medical Reviews – SQL Project
Data Cleaning • Data Modeling • Analytics • Insights

## Project Overview

This project analyzes Independent Medical Review (IMR) case data to uncover insights about treatment categories, reviewer decisions, patient demographics, and trends. The purpose is to demonstrate core SQL concepts including data cleaning, dimensional modeling, ETL logic, data validation, and analytical querying within a structured pipeline.

The project simulates how a real-world healthcare data team would transform raw IMR data into a clean, queryable analytics dataset.
